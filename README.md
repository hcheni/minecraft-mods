# Add-on Shelf

Minecraft Bedrock add-ons, served with GitHub Pages.

- `index.html` – the site
- `mods/` – the `.mcaddon` / `.mcpack` files people download. Any file uploaded here shows up on the site.
- `mods.json` – optional name, description, version and tags for each file
- `src/` – source folders for each add-on
