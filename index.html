Installing on iPad

  1. Tap Install on an add-on, then tap Download.
  2. Open the downloads list (the arrow in Safari's address bar) and tap the file.
  3. If it doesn't open by itself, tap Share and choose Minecraft.
  4. In your world's settings, turn the add-on on under Behavior Packs.
  5. Updating? Worlds keep using the version they were set up with. Remove the old version from the world's Behavior and Resource Packs, then add the new one.

Adding a new add-on

  1. Open this site's repository on GitHub and go into the mods folder.
  2. Tap Add file → Upload files and pick the .mcaddon or .mcpack file.
  3. Commit. It shows up here within a minute or two.
  4. To add a description, add an entry to mods.json.
