How to install

On iPad. On Windows, opening the downloaded file is enough for step 2.

  1. 1

    Download it

    Tap Download on an add-on. The file name ends in its version, such as -v1.9.mcaddon.

  2. 2

    Open it in Minecraft

    Open Safari's downloads list and tap the file. If it doesn't open by itself, tap Share and choose Minecraft.

  3. 3

    Turn it on in your world

    Edit the world and add the add-on under Behavior Packs. Its resource pack turns on with it.

Updating? A world keeps the version it was set up with. Remove the old version from the world's Behavior and Resource Packs, then add the new one.

Add a mod

Works from the GitHub app or github.com on any device.

  1. 1

    Open the mods folder

    In this site's repository on GitHub, go into the mods folder.

  2. 2

    Upload the file

    Tap Add file → Upload files and pick the .mcaddon or .mcpack. Put the version in the name, for example MyMod-v1.2.mcaddon.

  3. 3

    Commit

    It shows up here within a minute or two. To give it a description, tags or an icon, add an entry to mods.json.
